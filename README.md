# CJKV汉字: Singapore (新加坡)、Malaysia (马来西亚)

## Simplification Scheme

### Singapore

- [x] 1969/7，《简体字表》（502字简化为498字）（俗称502简体字表，手写体）
- [x] 1974/3，《简体字总表》（2275字简化为2287字）（俗称“2248简体字表”，实际2287字，手写体）
- [ ] 1976/1，《简体字总表》暂用本（2264字简化为2238字）
- [x] 1976/5，《简体字总表》修订本（2264字简化为2238字，印刷体）
    - 附录《异体字表》（1865字整理合并为810字）
    - 附录《新旧字形对照表》（共46字）
